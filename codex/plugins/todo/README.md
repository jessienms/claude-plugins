# 프로젝트 TODO (todo)

프로젝트에 붙어 있는, **세션이 끝나도 남는 할 일 목록**을 `.claude/todo/todo.md` 로 관리하는
스킬 플러그인입니다. "이거 todo에 추가해줘", "지금 할 일 뭐 남았어?" 같은 요청을 받으면
Codex가 이 스킬의 헬퍼 스크립트를 통해 목록을 다룹니다.

Codex의 계획(plan) 도구는 지금 이 세션의 작업 진행 상황을 추적하는 것이라 스레드가 끝나면
사라집니다. 이 플러그인은 "나중에 할 일"을 파일로 적어 두고, 며칠 뒤 다른 스레드에서
이어받기 위한 것입니다.

- **컨텍스트 절약**: 목록 조회는 **제목만**, 상세 조회는 **지정한 항목만**
- **완료는 삭제가 아니라 이동**: 항목당 마크다운 파일 하나로 `backup/` 에 보관
- **안정적인 ID**: `T7` 은 한 번 발급되면 재사용되지 않아 며칠 뒤에도 같은 항목을 가리킴
- **Claude Code판과 목록 공유**: 데이터 폴더가 같은 `.claude/todo/` 라 한쪽에서 적고 다른 쪽에서 이어받을 수 있음

## 설치

터미널에서 이 마켓을 추가한 뒤 설치합니다 (`codex` 서브커맨드):

```bash
codex plugin marketplace add jessienms/claude-plugins
codex plugin add todo@jessienms-codex-plugins
```

설치 후 **새 Codex 스레드**를 시작하면 로드됩니다. TUI에서는 `/plugins` 브라우저로도 설치할 수 있습니다.

> **명령어 없이 설치하려면** → [Codex 앱 화면에서 클릭으로 설치하기](../../README.md#a-codex-앱에서-설치하기) (스크린샷 안내)
> 앱의 마켓플레이스 추가 다이얼로그에서는 **출처** 칸에 `jessienms/claude-plugins` 만 입력하고
> **Git ref 와 Sparse 경로는 비워 두세요** — 흐리게 보이는 `main`/`plugins/codex` 는 입력값이 아니라 예시입니다.

## 사용법 — 이렇게 말하면 됩니다

스킬은 요청 내용으로 **자동 로드**되며, `$todo` 로 **수동 호출**할 수도 있습니다.
초기 설정은 필요 없습니다 — 첫 항목을 추가할 때 폴더와 파일이 만들어집니다.

- "방금 얘기한 재시도 로직, todo에 추가해줘" → 항목 추가
- "지금 할 일 뭐 남았어?" → 제목 목록
- "T7 상세 보여줘" → 항목 하나만 펼치기
- "아까 그거 작업 끝났어, 완료로 해줘" → 목록에서 빼고 백업으로 보관
- "이건 안 하기로 했으니 취소해" → 취소로 보관

### 시나리오

1. **작업 중 떠오른 일을 적어 두기**

   > "지금 하는 건 아니고, 로그인 실패했을 때 재시도하는 로직도 필요해. todo에 넣어줘"

   대화 맥락을 요약해 제목과 상세를 만들고 `T7` 로 추가합니다.

2. **며칠 뒤, 다른 스레드에서 목록 확인**

   > "할 일 목록 보여줘"

   ```
   T7    로그인 실패 시 재시도 로직  (상세 2줄)
   T9    결제 모듈 리팩터링  (상세 3줄)
   T12   README 오탈자 수정
   ```

   제목만 나오므로 목록이 길어져도 부담이 없습니다.

3. **하나만 펼쳐서 작업 시작**

   > "T7 내용 좀 보여줘"

   그 항목의 상세만 출력됩니다. 며칠 전 결정해 둔 내용이 그대로 남아 있습니다.

4. **끝났으면 완료 처리**

   > "재시도 로직 다 됐어. 할일에서 빼줘"

   목록에서 제거되고 `.claude/todo/backup/T7-로그인-실패-시-재시도-로직.md` 로 보관됩니다.
   어떻게 처리했는지 메모도 함께 남습니다.

## 파일 레이아웃

```
<프로젝트 루트>/.claude/todo/
├── todo.md                      진행 중인 항목만
├── .seq                         ID 카운터
└── backup/
    ├── T7-로그인-실패-시-재시도-로직.md
    └── T12-README-오탈자-수정.md
```

`todo.md` 는 사람이 읽어도 되는 평범한 마크다운 체크리스트입니다:

```markdown
- [ ] (T7) 로그인 실패 시 재시도 로직 <!-- added:2026-07-31 -->
  - 401 이면 토큰 갱신 후 1회 재시도
  - 3회 실패 시 로그아웃
```

ID(`T7`)는 한 번 발급되면 재사용되지 않으므로, 항목이 빠져도 다른 항목의 번호가 밀리지 않습니다.

`.claude/todo/` 를 커밋할지는 프로젝트에 따라 정하세요 — 팀과 공유하려면 커밋하고,
개인 메모라면 `.gitignore` 에 넣으면 됩니다.

## Codex에서 쓸 때 알아둘 점

- **데이터 폴더 이름이 `.claude/` 입니다.** Claude Code판과 **같은 폴더를 공유**하기 위해서입니다.
  Codex만 쓰는 프로젝트에서도 경로는 그대로이며, 동작에는 아무 영향이 없습니다.
- **git 저장소면 루트를 자동으로 찾습니다.** 저장소가 아니면 **현재 작업 폴더** 기준이라,
  하위 폴더에서 작업 중이라면 "todo 폴더는 `<프로젝트루트>/.claude/todo` 야"라고 알려주면
  `--dir` 로 지정해 실행합니다.
- **삭제성 동작은 확인 후 다음 턴에 실행합니다.** Codex에는 선택지 UI가 없으므로, 어느 항목인지
  애매하면 스킬이 후보를 나열하고 턴을 끝냅니다. 승인 정책을 full-auto로 두어도 마찬가지입니다 —
  쉘 명령이 자동 승인되는 것과 "이 항목을 지워도 좋다"는 승인은 별개입니다.
- **Windows에서는 Git for Windows의 bash가 필요합니다.** 스크립트가 bash로 작성돼 있어
  `bash <경로>/todo.sh ...` 로 호출됩니다.

## 직접 실행

스킬 없이 스크립트만 따로 쓸 수도 있습니다:

```bash
bash scripts/todo.sh add --title "제목" --body "- 상세"
bash scripts/todo.sh list
bash scripts/todo.sh show T7
bash scripts/todo.sh done T7 --note "이렇게 처리함"
bash scripts/todo.sh cancel T9
bash scripts/todo.sh log
bash scripts/todo.sh --help
```

## 요구 사항

- bash (Git for Windows에 포함, macOS/Linux는 기본 제공)
- git 저장소면 루트를 자동으로 찾습니다. 아니면 현재 디렉터리 기준이며 `--dir` 로 지정할 수 있습니다.
