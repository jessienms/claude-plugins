# todo

프로젝트에 붙어 있는, **세션이 끝나도 남는 할 일 목록**을 `.claude/todo/todo.md` 로 관리합니다.

Claude Code 기본 `TodoWrite` 는 지금 이 세션의 작업 진행 상황을 추적하는 도구라 대화가 끝나면 사라집니다. 이 플러그인은 "나중에 할 일" 을 파일로 적어 두고, 며칠 뒤 다른 세션에서 이어받기 위한 것입니다.

## 컨텍스트를 아끼는 구조

할 일 목록은 시간이 지나면 커집니다. 항목 하나를 완료 처리하려고 `todo.md` 를 통째로 읽으면 무관한 항목 수십 개의 상세 내용까지 전부 컨텍스트에 올라옵니다.

그래서 모든 동작이 헬퍼 스크립트를 거칩니다 — 목록 조회는 **제목만**, 상세 조회는 **지정한 항목만**, 완료 처리는 **해당 블록만** 잘라내 백업으로 옮깁니다. 완료된 항목은 `backup/` 에 항목당 파일 하나로 쌓이므로, 필요한 하나만 열어 볼 수 있습니다.

## 설치

마켓플레이스를 아직 추가하지 않았다면 [메인 README](../../README.md)를 참고하세요.

```
/plugin install todo@jessienms-plugins
```

## 사용법

설치 후에는 Claude Code에게 자연스럽게 말하면 됩니다:

- "방금 얘기한 재시도 로직, todo에 추가해줘" → 항목 추가
- "지금 할 일 뭐 남았어?" → 제목 목록
- "T7 상세 보여줘" → 항목 하나만 펼치기
- "T7 제목 이렇게 바꿔줘", "거기에 이 내용도 적어둬" → ID 유지한 채 제자리 수정
- "아까 그거 작업 끝났어, 완료로 해줘" → 목록에서 빼고 백업으로 보관
- "이건 안 하기로 했으니 취소해" → 취소로 보관

### 시나리오

1. **작업 중 떠오른 일을 적어 두기**

   > "지금 하는 건 아니고, 로그인 실패했을 때 재시도하는 로직도 필요해. todo에 넣어줘"

   대화 맥락을 요약해 제목과 상세를 만들고 `T7` 로 추가합니다.

2. **며칠 뒤, 다른 세션에서 목록 확인**

   > "할 일 목록 보여줘"

   ```
   T7    로그인 실패 시 재시도 로직  (상세 2줄)
   T9    결제 모듈 리팩터링  (상세 3줄)
   T12   README 오탈자 수정
   ```

   제목만 나오므로 목록이 길어져도 부담이 없습니다.

3. **하나만 펼쳐서 작업 시작**

   > "T7 내용 좀 보여줘"

   그 항목의 상세만 출력됩니다. 며칠 전 결정해 둔 내용이 그대로 남아 있습니다.

4. **내용이 바뀌었으면 그 자리에서 수정**

   > "T7 에 백오프는 2s/4s 로 하기로 했다고 적어둬"

   상세 끝에 한 줄이 덧붙습니다. 제목만 바꾸거나 상세를 통째로 다시 쓸 수도 있고,
   **ID(`T7`)와 등록 날짜는 그대로 유지**됩니다 — 취소 후 재등록이 아닙니다.

5. **끝났으면 완료 처리**

   > "재시도 로직 다 됐어. 할일에서 빼줘"

   목록에서 제거되고 `.claude/todo/backup/T7-로그인-실패-시-재시도-로직.md` 로 보관됩니다. 어떻게 처리했는지 메모도 함께 남습니다.

## 파일 레이아웃

```
<프로젝트 루트>/.claude/todo/
├── todo.md                      진행 중인 항목만
├── .seq                         ID 카운터
└── backup/
    ├── T7-로그인-실패-시-재시도-로직.md
    └── T12-README-오탈자-수정.md
```

`todo.md` 는 사람이 읽어도 되는 평범한 마크다운 체크리스트입니다:

```markdown
- [ ] (T7) 로그인 실패 시 재시도 로직 <!-- added:2026-07-31 -->
  - 401 이면 토큰 갱신 후 1회 재시도
  - 3회 실패 시 로그아웃
```

ID(`T7`)는 한 번 발급되면 재사용되지 않으므로, 항목이 빠져도 다른 항목의 번호가 밀리지 않습니다.

`.claude/todo/` 를 커밋할지는 프로젝트에 따라 정하세요 — 팀과 공유하려면 커밋하고, 개인 메모라면 `.gitignore` 에 넣으면 됩니다.

## 직접 실행

스크립트만 따로 쓸 수도 있습니다:

```bash
bash scripts/todo.sh add --title "제목" --body "- 상세"
bash scripts/todo.sh list
bash scripts/todo.sh show T7
bash scripts/todo.sh edit T7 --title "새 제목"
bash scripts/todo.sh edit T7 --append "- 덧붙일 상세"
bash scripts/todo.sh edit T7 --body "- 상세를 통째로 교체"
bash scripts/todo.sh done T7 --note "이렇게 처리함"
bash scripts/todo.sh cancel T9
bash scripts/todo.sh log
bash scripts/todo.sh --help
```

## 요구 사항

- bash (Git for Windows에 포함, macOS/Linux는 기본 제공)
- git 저장소면 루트를 자동으로 찾습니다. 아니면 현재 디렉터리 기준이며 `--dir` 로 지정할 수 있습니다.
