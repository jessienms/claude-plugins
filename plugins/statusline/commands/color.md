# 워크트리 색상 지정

status line 1줄의 워크트리명 앞에 표시되는 색 네모(`(█ DevA)`)를 설정한다. 색이 지정되지 않은 워크트리는 네모 없이 `(DevA)` 로만 표시된다.

사용자 입력: `$ARGUMENTS`

## 설정 파일

파일명은 `statusline-worktree-colors`, 위치는 두 곳이다.

| 우선순위 | 경로 | 용도 |
|---|---|---|
| 1 | `<메인 체크아웃 루트>/.claude/statusline-worktree-colors` | 이 프로젝트 전용 |
| 2 | `~/.claude/statusline-worktree-colors` | 모든 프로젝트 공통 |

**키 단위 병합**이다. 프로젝트 파일에 해당 워크트리 키가 있으면 그 값을 쓰고, 없으면 전역 파일에서 찾는다. 기본값을 전역에 두고 특정 프로젝트만 덮어쓸 수 있다.

포맷:

```
# 주석은 이렇게
DevA=#8AADF4
DevB=green
hotfix=237;135;150
```

- 키 = **워크트리 폴더명** (브랜치명이 아니다). 대소문자를 구분하지 않는다.
- 값 = `#RRGGBB` / `#RGB` / `R;G;B` / 프리셋 이름
- 잘못된 값은 status line에서 조용히 무시되어 네모만 생략된다

## 경로 해석

메인 체크아웃 루트는 다음 순서로 구한다:

```bash
git rev-parse --git-common-dir
```

- 결과가 절대경로(`C:/...` 또는 `/...`)면 → 그 **dirname**이 메인 체크아웃 루트다 (linked worktree에서 실행한 경우)
- 결과가 상대경로(`.git`)면 → 메인 체크아웃에서 실행 중이므로 `git rev-parse --show-toplevel` 이 루트다

`--path-format=absolute` 는 git 2.31+ 에서만 동작하므로 쓰지 않는다.

현재 워크트리 폴더명은 `basename "$(git rev-parse --show-toplevel)"` 이다.

## 프리셋 이름

| 이름 | 값 | 이름 | 값 |
|---|---|---|---|
| `blue` | `#8AADF4` | `teal` | `#8BD5CA` |
| `green` | `#A6DA95` | `pink` | `#F5BDE7` |
| `red` | `#ED8796` | `sky` | `#91D7E3` |
| `yellow` | `#EED49F` | `flamingo` | `#F0C6C6` |
| `mauve` | `#C6A0F6` | `gray` (`grey`) | `#6E738D` |
| `peach` (`orange`) | `#F5A97F` | | |

## 수행할 동작

`$ARGUMENTS` 를 해석해서 아래 중 하나를 수행한다. 자연어로 들어와도(예: "DevA를 파란색으로", "DevB 색 지워줘") 같은 규칙으로 해석한다.

### 인자 없음 → 조회

1. 현재 워크트리 폴더명과 메인 체크아웃 루트를 위 방법으로 구해 알려준다
2. 두 설정 파일을 읽어 항목을 표로 보여준다. 각 항목마다 어느 파일에서 왔는지(프로젝트/전역), 그리고 프로젝트 값이 전역 값을 덮어쓰고 있으면 그 사실을 표시한다
3. 파일이 하나도 없으면 아직 지정된 색이 없다고 알리고 지정 방법을 예시로 보여준다

### `<워크트리명> <색>` → 지정

- 워크트리명을 생략하면 **현재 워크트리**를 대상으로 한다
- `--global` 이 있으면 전역 파일, 없으면 프로젝트 파일에 쓴다
- 색이 프리셋 이름도 아니고 `#RRGGBB`/`#RGB`/`R;G;B` 형식도 아니면 지정하지 말고 유효한 형식을 안내한다
- 대상 파일이 없으면 새로 만든다. `.claude/` 디렉터리가 없으면 함께 만든다
- 파일이 이미 있으면 **다른 줄과 주석을 그대로 보존**하고, 해당 키의 줄만 교체한다(키 매칭은 대소문자 무시). 키가 없으면 파일 끝에 한 줄 추가한다
- 새로 만드는 파일에는 맨 위에 주석 한 줄을 넣는다:
  ```
  # statusline 워크트리 색상: 워크트리폴더명=색 (#RRGGBB | #RGB | R;G;B | 프리셋명)
  ```

### `<워크트리명> --clear` → 해제

해당 키의 줄만 제거한다. `--global` 이면 전역 파일에서, 아니면 프로젝트 파일에서 제거한다. 키가 없으면 그렇다고 알려준다.

## 완료 안내

- 변경된 파일 경로와 결과 줄을 보여준다
- **재설치는 필요 없다.** 설정은 스크립트 바깥 파일이므로 다음 status line 렌더부터 바로 반영된다
- 메인 체크아웃(linked worktree가 아닌 곳)에서는 워크트리명 자체가 표시되지 않으므로 네모도 나오지 않는다는 점을 필요할 때 안내한다
